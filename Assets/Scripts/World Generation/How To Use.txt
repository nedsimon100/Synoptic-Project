Chunk Settings:

- max chunk per frame - adjust for faster generation or higher frame rate
- chunk size - how many points are sampled from each point, rounded to nearest power of 2
- load dist - distance at which chunks are generated
- Deletion Dist - distance at which chunks are unloaded
- Player - gameobject that chunks are generated around
- seed - deterministic setting for specific generation if 0 it is randomised
- chunk prefab - base chunk gameobject that is used for generation, must contain chunk script

Map Settings:

- mapsize - the amount of map points saved to memory of each noise map generated which is then multiplied by the thread count used in the compute shader

- foliage density map:
|- map used to spawn foliage in different density's across the generated world
-- scale - distance between sample points of noise map (bicubicly interpolated)
-- max height - if equal to 0 no foliage spawns
gradient Dampening - redundant, only used in fractal height maps

- base world map:
|- map used for generating different water levels for lakes and rivers by raising ground and water level proportional to its height 
-- scale - distance between sample points of noise map (bicubicly interpolated)
-- max height - the maximum height added onto the fractal maps
gradient Dampening - redundant, only used in fractal height maps

- base World Sea Level - lowest water height proportional to overall max land height
- River and lake density - how much the water height increases proportional to base world map height

Land Settings:

- Maps:
|- the fractal noise maps used to generate the world map must be ordered from greatest scale to lowest
-- scale - distance between sample points on the generated noise map (bicubicly interpolated)
-- max height - maximum height of a sample point
-- gradient dampening - reduces the height of a sample point proportional to the gradient of the larger scale layers of the fractal noise map

- Temperature Map:
|- the map used to generate biomes when paired with the humidity map
-- scale - distance between sample points on temperature map (bicubicly interpolated)
-- max height - max temperature
-- gradient dampening - redundant

- Humidity Map:
|- the map used to generate biomes when paired with the Temperature map
-- scale - distance between sample points on Humidity map (bicubicly interpolated)
-- max height - max Humidity 
-- gradient dampening - redundant

-Biomes:
|- list of all the possible biomes that can be used in the world generation
-- temperature - the temp at which the biome is generated by closest neighbour  on the temperature map
-- Humidity - the humidity at which the biome is generated by closest neighbour on the humidity map
-- Height Mult - how much the fractal noises height is multiplied by in the biome
-- height colour - the base colours for the biome above sea level
-- Sea Colour - the water colour in a given biome based off of depth
-- sea Floor Colour - the base colours for the biome below sea level

-- Height Layers:
|-- list of terrain layers that can be used per biome, need to be ordered from lowest to highest and at least one required by each biome
--- min height - -1 = max depth 0 = water level 1 = max height |the lowest height a height layer is used
--- blend range - the distance at which the height layer is blended bellow the min height with the height layer bellow it
--- foliage spawn density - the amount of foliage spawned in the height layer based off of the foliage density map
--- weight - how much the normal and diffuse maps are used opposed to the base colours of the biome
--- normal map scale - the height multiplier for the normal map
--- texture scale - the tile size for the normal and diffuse map
--- smoothness - the smoothness scale used by the terrain layer
--- metallic - the metallic value of the terrain layer
--- normal map - the normal map used for the terrain layer
--- diffuse texture - the diffuse texture used for the terrain layer

--- foliage:
|--- the possible foliage that can be spawned on a height layer in a biome
---- Obj - the gameobject to be spawned
---- min height - minimum height multiplier for the obj local scale
---- max height - maximum possible height multiplier for the obj local scale
---- min width - minimum width multiplier for the obj local scale
---- max width - maximum width multiplier for the obj local scale
---- spawn chance - the probability of this object spawning as a ratio of all of a height layers foliage spawn chances
